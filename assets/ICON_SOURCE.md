# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/checkmk.svg` | Default (light mode) |
| `icon-dark.svg` | `svg/checkmk-light.svg` | Light-colored logo for dark mode |
| `icon-light.svg` | `svg/checkmk-dark.svg` | Dark-colored logo for light backgrounds |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/checkmk.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/checkmk-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/checkmk-dark.svg
